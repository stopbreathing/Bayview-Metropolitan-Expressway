Welcome to the official development repository for the ultimate **Need for Speed: Underground 2** map overhaul and extension project. 

## 🛠️ Project Goals & Infrastructure Overview
This project aims to fix fundamental scale issues of Bayview and physically integrate the **NFS Underground 1 map** into a unified, seamless free-roam experience.

* **Inter-City Highway Connectors**: Building a massive, high-detail bridge system linking the worlds of UG1 and UG2.
* **Metropolitan Scale Correction**: Total overhaul of low-poly assets, resizing oversized palm trees, and fixing miniature road signs to achieve realistic proportions.
* **Track Integration**: Relocating and embedding isolated tracks (Stadium, Street-X, Drift arenas) directly into the main free-roam world geometry.
* **Beta Restoration**: Reconstructing cut highways and unused zones based on 2004 beta files.
* **Desert Drive Region**: Full scratch-built construction of the legendary cut desert environment.
